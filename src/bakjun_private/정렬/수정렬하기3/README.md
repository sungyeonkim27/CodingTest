# BOJ 10989 - 수 정렬하기 3

## 📌 문제 요약
N개의 수가 주어졌을 때, 이를 오름차순으로 정렬하는 문제.  
입력 크기가 매우 크고, 메모리 제한이 빡빡해 단순 정렬로는 해결하기 어렵다.

---

## 🚨 제한 사항
- N ≤ 10,000,000 (천만 개의 수)
- 값의 범위: 1 ≤ Ai ≤ 10,000 (자연수, 중복 가능)
- 시간 제한: 5초
- 메모리 제한: 8MB

---

## 💡 풀이 아이디어
- 입력 크기(N)가 매우 크기 때문에 `O(N log N)` 정렬(`Arrays.sort`)은 비효율적.
- 값의 범위(1~10,000)가 작으므로 **계수 정렬(Counting Sort)** 적용.
    - 등장 횟수를 저장하는 배열(`count[num]`)을 사용.
    - 1부터 10,000까지 순차적으로 출력.
- 입출력은 `Scanner`/`System.out.println` 대신
    - **BufferedReader** (빠른 입력)
    - **StringBuilder** (출력 모아두기 후 한 번에 출력)
      를 사용해야 시간 제한 내에 통과 가능.

---

## 📈 배운 점
- 입력 범위가 작고 개수가 많을 때는 **계수 정렬**이 정답.
- 문제 조건(값의 범위, 메모리 제한)을 분석하는 것이 알고리즘 선택의 핵심.
- 자바에서 대용량 입출력 문제는 반드시 **BufferedReader + StringBuilder** 조합이 필요하다.
