208. Trie (Prefix Tree) 구현하기
     문제 설명:
     **Trie(트라이)**는 문자열 데이터셋에서 키를 효율적으로 저장하고 검색하는 트리 자료구조입니다. 자동완성, 맞춤법 검사 등에 활용됩니다.
     구현해야 할 것:

Trie() - 생성자: 트라이 객체를 초기화합니다
void insert(String word) - 문자열 word를 트라이에 삽입합니다
boolean search(String word) - 문자열 word가 트라이에 있으면 true, 없으면 false를 반환합니다
boolean startsWith(String prefix) - prefix로 시작하는 단어가 이전에 삽입되었으면 true, 아니면 false를 반환합니다

예제 설명:
Trie trie = new Trie();
trie.insert("apple");        // "apple" 삽입
trie.search("apple");        // true 반환 (apple이 있음)
trie.search("app");          // false 반환 (app은 삽입 안 했음)
trie.startsWith("app");      // true 반환 (apple이 app으로 시작함)
trie.insert("app");          // "app" 삽입
trie.search("app");          // true 반환 (이제 app도 있음)
핵심 차이점:

search("app"): "app"이라는 완전한 단어가 삽입되었는지 확인
startsWith("app"): "app"으로 시작하는 단어가 있는지 확인

제약 조건:

단어/접두사 길이: 1 ~ 2000
소문자 알파벳만 사용
총 함수 호출 횟수: 최대 30,000번
