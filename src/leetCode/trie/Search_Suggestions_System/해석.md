문제 해석
검색 추천 시스템 (Search Suggestions System)
문제 설명:

products 배열(상품명 목록)과 searchWord 문자열이 주어집니다
사용자가 searchWord를 한 글자씩 타이핑할 때마다, 현재까지 입력된 문자열과 같은 접두사(prefix)를 가진 상품을 최대 3개까지 추천해야 합니다
추천 상품이 3개 이상이면, 사전순(lexicographically)으로 가장 앞선 3개만 반환합니다
각 문자를 입력할 때마다의 추천 결과를 리스트의 리스트로 반환합니다

예시 1:

입력: products = ["mobile","mouse","moneypot","monitor","mousepad"], searchWord = "mouse"
"m" 입력 → ["mobile","moneypot","monitor"]
"mo" 입력 → ["mobile","moneypot","monitor"]
"mou" 입력 → ["mouse","mousepad"]
"mous" 입력 → ["mouse","mousepad"]
"mouse" 입력 → ["mouse","mousepad"]

핵심 포인트:

매 타이핑마다 현재 prefix와 일치하는 상품 찾기
사전순 정렬 후 최대 3개만 선택
각 단계별 결과를 저장


풀이
접근 방법 1: 정렬 + 이진 탐색
javaclass Solution {
public List<List<String>> suggestedProducts(String[] products, String searchWord) {
List<List<String>> result = new ArrayList<>();

        // 1. products를 사전순으로 정렬
        Arrays.sort(products);
        
        // 2. searchWord의 각 문자를 하나씩 추가하면서 검색
        StringBuilder prefix = new StringBuilder();
        
        for (char c : searchWord.toCharArray()) {
            prefix.append(c);
            List<String> suggestions = new ArrayList<>();
            
            // 3. 현재 prefix로 시작하는 상품 찾기
            for (String product : products) {
                if (product.startsWith(prefix.toString())) {
                    suggestions.add(product);
                    // 최대 3개까지만
                    if (suggestions.size() == 3) {
                        break;
                    }
                }
            }
            
            result.add(suggestions);
        }
        
        return result;
    }
}
시간 복잡도: O(n log n + m * n)

n: products 길이, m: searchWord 길이
정렬: O(n log n)
각 문자마다 전체 배열 순회: O(m * n)


접근 방법 2: Trie (트라이) 사용 - 최적화
javaclass Solution {
// Trie 노드 정의
class TrieNode {
Map<Character, TrieNode> children = new HashMap<>();
List<String> suggestions = new ArrayList<>(); // 각 노드에 최대 3개 상품 저장
}

    class Trie {
        TrieNode root = new TrieNode();
        
        // Trie에 단어 삽입
        void insert(String word) {
            TrieNode node = root;
            for (char c : word.toCharArray()) {
                node.children.putIfAbsent(c, new TrieNode());
                node = node.children.get(c);
                
                // 각 노드에 사전순으로 최대 3개까지만 저장
                if (node.suggestions.size() < 3) {
                    node.suggestions.add(word);
                }
            }
        }
        
        // prefix로 시작하는 추천 상품 검색
        List<String> search(String prefix) {
            TrieNode node = root;
            
            // prefix를 따라 내려가기
            for (char c : prefix.toCharArray()) {
                if (!node.children.containsKey(c)) {
                    return new ArrayList<>(); // prefix가 없으면 빈 리스트
                }
                node = node.children.get(c);
            }
            
            return node.suggestions;
        }
    }
    
    public List<List<String>> suggestedProducts(String[] products, String searchWord) {
        // 1. products를 사전순으로 정렬
        Arrays.sort(products);
        
        // 2. Trie 구축
        Trie trie = new Trie();
        for (String product : products) {
            trie.insert(product);
        }
        
        // 3. searchWord의 각 문자를 추가하며 검색
        List<List<String>> result = new ArrayList<>();
        StringBuilder prefix = new StringBuilder();
        
        for (char c : searchWord.toCharArray()) {
            prefix.append(c);
            result.add(trie.search(prefix.toString()));
        }
        
        return result;
    }
}
시간 복잡도: O(n log n + nL + mL)

n: products 길이, L: 평균 상품명 길이, m: searchWord 길이
정렬: O(n log n)
Trie 구축: O(n * L)
검색: O(m * L)

공간 복잡도: O(n * L) - Trie 저장 공간

접근 방법 3: 이진 탐색 최적화
javaclass Solution {
public List<List<String>> suggestedProducts(String[] products, String searchWord) {
List<List<String>> result = new ArrayList<>();
Arrays.sort(products);

        StringBuilder prefix = new StringBuilder();
        int start = 0; // 검색 시작 위치를 기억
        
        for (char c : searchWord.toCharArray()) {
            prefix.append(c);
            
            // 이진 탐색으로 시작 위치 찾기
            start = binarySearch(products, start, prefix.toString());
            
            List<String> suggestions = new ArrayList<>();
            for (int i = start; i < Math.min(start + 3, products.length); i++) {
                if (products[i].startsWith(prefix.toString())) {
                    suggestions.add(products[i]);
                } else {
                    break;
                }
            }
            
            result.add(suggestions);
        }
        
        return result;
    }
    
    private int binarySearch(String[] products, int start, String prefix) {
        int left = start, right = products.length;
        
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (products[mid].compareTo(prefix) < 0) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        
        return left;
    }
}
